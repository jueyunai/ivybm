# 客户演示素材来源

## 使用边界

- 本目录记录 `src/seed/assets/showcase/` 中 8 张客户演示图片的来源与校验值。
- 这些图片来自客户确认原型中使用的 Unsplash 图片地址，仅用于 staging / 线上客户演示和版式效果确认，不视为客户正式品牌资产。
- 图片已随仓库保存，运行时通过 Payload Media 上传，不从前端热链 Unsplash。
- 最终 production 验收前，必须由客户提供或确认可长期使用的品牌、工厂、产品与项目图片；正式媒体保存在仓库外并通过 Payload Media 受控上传，不替换本目录占位图。
- 不得删除本清单中的来源 URL 或把素材描述为客户自有图片。

## 替换流程

1. 客户确认正式图片及长期使用权。
2. 将正式媒体保存到仓库外受控资料目录；不得覆盖 `src/seed/assets/showcase/`，不得加入 Git 或 Docker 构建上下文。
3. 本地预览按需从外部目录导入到隔离 Payload Media；production 在备份数据库与媒体卷后通过 CMS 上传并填写 ALT、source 与 `isPublic`。
4. 更新产品、项目、新闻、About 等 CMS 记录的媒体引用，并验证正式媒体 URL。
5. 更新英文 / 阿语、desktop / tablet / mobile 视觉基线，复跑官网功能 E2E、视觉 E2E、production build 和 Design QA。
