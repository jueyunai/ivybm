# 一期平台账号接入运行手册

适用范围：Task 13 的 Facebook、Instagram、TikTok、LinkedIn 条件接入。没有任何真实账号时也可保留本手册和后台配置结构；不得用假账号、假 Token 或客户密码替代。

## 当前后台能力

`/admin/collections/platform-accounts` 仅管理员可访问。每条记录可先保存为“未开始”，后续再补外部账号 ID、App ID、授权状态和能力审核状态。

- access token 与 refresh token 是只写字段，以 `PLATFORM_CREDENTIAL_ENCRYPTION_KEY` 加密；后台、REST、GraphQL、审计日志和 readiness 接口均不回显。
- `GET /api/platforms/readiness` 仅管理员可调用，返回不含令牌的配置缺口与代码/平台阻塞原因。
- 这只表示“系统已准备接入”，不表示平台已经 `available`。

## 账号到手后的最短路径

1. 在服务器 `.env` 设置独立的 `PLATFORM_CREDENTIAL_ENCRYPTION_KEY`，运行 production preflight 并发布 app / worker；不要把该值发到聊天工具。
2. 由客户保留资产 Owner 和至少两名长期管理员；客户只授予可撤销的人员、开发者或合作伙伴权限，不提供密码。
3. 在“平台账号”创建对应记录，填写真实的外部账号 ID 和非敏感 App ID；Token 只在受保护后台录入。
4. 以管理员身份请求 `/api/platforms/readiness`，按返回的 `missing` 完成环境和账号配置。
5. 仅在 production 受控窗口完成签名、OAuth/授权、Webhook 或测试发布后，才把 PoC 状态改为 `available`。

`missing=credential_decryption` 表示数据库中已有令牌，但当前 app / worker 无法用
`PLATFORM_CREDENTIAL_ENCRYPTION_KEY` 验证它；它不会把令牌回显。恢复原来的密钥，或先将账号
设为非连接状态、撤销旧令牌并重新授权录入。不要仅凭 `accessTokenConfigured=true` 把账号标为可用。

| 账号类型 | 一期用途 | 现在的真实状态 |
| --- | --- | --- |
| `facebook-page` | Messenger 入站、Facebook 图文 | 入站 route 已实现；图文发布等待 Task 12 发布任务结构与 Meta 授权 |

## Meta 额外要求

Facebook Page / Instagram Professional Account 的入站配置还需要 app 级环境变量同时存在：

```text
META_WEBHOOK_APP_SECRET
META_WEBHOOK_VERIFY_TOKEN
META_WEBHOOK_ALLOWED_ACCOUNT_IDS
```

allowlist 必须包含对应外部账号 ID。三项任一缺失时 route 会安全返回不可用，不会连接数据库或接受未经授权的 Webhook。App Secret 与 verify token 不保存到“平台账号”记录。

## 明确的边界

- TikTok 没有目标地区官方 Business Messaging/DM 资格和官方事件 schema 前，不创建猜测性 Webhook parser，不使用浏览器自动化绕过。
- 即使后台已保存 TikTok Business 账号，默认 worker 仍拒绝 TikTok 规范化事件；只有官方 schema、资格、connector、fixture 和跨人代码 review 全部具备后，才可由新的代码显式启用该内部投递路径。
- 已连接账号如需改为另一条 Page / Professional Account / Member / Organization ID，必须同时重新录入或清除全部已配置的 access / refresh token；系统拒绝“旧 Token + 新外部账号 ID”的保存，避免误报连接可用。
- 首条 TikTok 会话写入后，不得为了回退旧镜像而强行执行 TikTok channel migration 的 `down`；该回滚会故意失败以保护新数据，应恢复到新镜像或按备份/前向修复流程处理。
- LinkedIn、Facebook、Instagram 的真实图文发布持久化仍依赖 Task 12 的 `PublishJobs` / `PublishLogs` 合并；在此之前只能保留 capability、配置、格式化和人工发布路径。
- WhatsApp、LinkedIn 私信、TikTok 图文发布不属于一期系统接入范围。
