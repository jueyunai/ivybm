# 海外社媒消息接入费用说明（面客版）

日期：2026-06-24

> 说明：以下费用只说明「平台官方 API / 消息通道费用」，不包含系统开发费、AI 模型调用费、服务器费、广告投放费、第三方聚合平台服务费。美元按 `1 USD ≈ 6.8 RMB` 粗算，最终以付款当天汇率和平台账单为准。

## 1. 一句话结论

第一阶段最适合接入的是：官网 AI 客服 + WhatsApp + Facebook / Instagram。

- 官网 AI 客服：收消息、回消息都没有社媒平台费用。
- WhatsApp：客户主动来问，我们收消息免费；24 小时内正常回复客户免费；主动群发 / 主动营销才按条收费。
- Facebook / Instagram：官方 API 目前不按「每条消息」收费，主要成本是账号授权、平台审核、系统开发和后续维护。
- LinkedIn：不是买会员就能 API 接入私信，第一阶段不建议承诺自动接私信。
- TikTok：有商业消息 API 方向，但需要账号和地区审核，第一阶段建议先不承诺。
- YouTube：适合接评论，不适合接私信；API 是免费配额制。

## 3. WhatsApp 按条费用说明

WhatsApp 是唯一需要重点单列「每条消息费用」的平台。费用按「客户所在国家 + 消息类型」计算。

### 3.1 客户主动咨询

| 场景 | 收费 |
|------|------|
| 客户发一条消息给我们 | 0 元 |
| 我们在 24 小时内正常回复客户 | 0 元 |
| 客户从点击 WhatsApp 广告或 Facebook 页面按钮进入后，72 小时内沟通 | 通常 0 元 |

面客解释：

> 只要客户是主动来咨询，我们在服务窗口内正常回复，WhatsApp 官方消息费基本可以按 0 估算。第一阶段做 AI 客服筛选和人工接管，不会产生明显消息成本。

### 3.2 我们主动发营销消息

主动营销消息是指：客户没有刚刚来问，企业主动给客户发促销、开发、唤醒、产品推荐等消息。这类消息需要使用 WhatsApp 模板，并按送达条数收费。

按 2026-06-24 官方报价抽样，粗略换算如下：

| 客户所在地区 | 主动营销发 1 条 | 主动营销发 1000 条 |
|--------------|----------------|--------------------|
| 美国 / 加拿大 | 约 0.17 元 | 约 170 元 |
| 阿联酋 | 约 0.34 元 | 约 339 元 |
| 沙特 | 约 0.34 元 | 约 341 元 |
| 卡塔尔等中东其他地区 | 约 0.23 元 | 约 232 元 |
| 澳洲等亚太地区 | 约 0.50 元 | 约 498 元 |

### 3.3 非营销通知消息

如果是报价单提醒、订单状态、资料确认、预约提醒等非营销类通知，单条费用通常比营销消息低：

| 客户所在地区 | 通知 / 认证类发 1 条 | 通知 / 认证类发 1000 条 |
|--------------|----------------------|--------------------------|
| 美国 / 加拿大 | 约 0.02 元 | 约 23 元 |
| 阿联酋 | 约 0.11 元 | 约 107 元 |
| 沙特 | 约 0.07 元 | 约 73 元 |
| 卡塔尔等中东其他地区 | 约 0.06 元 | 约 62 元 |
| 澳洲等亚太地区 | 约 0.08 元 | 约 77 元 |

注意：

- WhatsApp 实际是按美元结算，人民币只是估算。
- 平台按「送达」计费，不是我们点了发送就一定计费。
- 主动营销模板需要平台审核，不是想发什么就发什么。
- 如果走第三方 BSP / 聚合平台，第三方可能会在官方费用之外加收月费、席位费、消息加价或最低消费。

## 4. 其他平台会员 / 低消说明

### 4.1 Facebook / Instagram

客户需要准备：

- Facebook Page。
- Instagram 专业账号。
- Meta Business 业务资产。
- Meta App 权限审核。

费用口径：

- 接收消息：0 元平台消息费。
- 回复消息：0 元平台消息费。
- API 会员：不需要。
- 低消：API 接入本身无公开低消。
- 广告费：如果投 Facebook / Instagram 广告，广告预算另算，不属于 API 费用。

面客解释：

> Facebook 和 Instagram 的主要问题不是每条消息多少钱，而是能不能顺利通过 Meta 审核。审核通过后，日常收发客户私信不按条收费。

### 4.2 LinkedIn

客户可能会问：买 Sales Navigator 能不能接私信 API？

答案：不能这样承诺。

费用口径：

- LinkedIn 普通私信 API 不适合普通开发者自助接入。
- Sales Navigator 是人工找客户和销售开发工具，不等于开放私信 API。
- Sales Navigator / Premium 价格按 LinkedIn 当时页面和账号地区为准，通常是按人 / 月订阅；如需购买，由甲方自理。
- 如果使用第三方领英自动化工具，通常会有月费，但有封号风险，需要单独确认。

面客解释：

> LinkedIn 第一阶段建议做「AI 辅助人工开发」：系统帮业务员写话术、整理客户资料、记录跟进提醒，不承诺自动读取和自动回复 LinkedIn 私信。

### 4.3 TikTok

费用口径：

- TikTok Business Messaging 有 API 方向，但需要 TikTok Business 账号、开发者应用和平台审核。
- 官方公开资料中没有适合本项目直接套用的「每条私信多少钱」标准报价。
- 如果通过第三方聚合平台接 TikTok 私信，通常会有第三方月费、席位费或套餐费。
- TikTok 私信能力还受账号注册地区和用户地区影响。

面客解释：

> TikTok 第一阶段建议只做内容发布和主页引导，把客户引导到官网或 WhatsApp；私信 API 放到二期做 PoC，不写进第一阶段固定承诺。

### 4.4 YouTube

费用口径：

- YouTube 没有适合作为客服入口的私信 API。
- 可以接评论：读取评论、回复评论、把评论线索入库。
- YouTube API 是免费配额制，不是按条收费。
- 默认每天有 10000 units 配额，普通读取评论消耗很低；超出配额需要申请审核，不是直接买会员。

面客解释：

> YouTube 适合做展示和评论线索捕捉，不适合做统一私信客服。

## 5. 建议写进报价单的费用边界

建议在报价单里写：

> 本报价包含系统开发与首批平台接入配置，不包含 WhatsApp 官方消息费、广告投放费、第三方 BSP / 聚合平台服务费、LinkedIn / TikTok 等平台会员费或自动化工具费。以上费用如实际发生，由甲方账户直接支付，或按平台账单另行结算。

也建议写清：

> 第一阶段优先接入官网 AI 客服、WhatsApp、Facebook / Instagram 客户主动咨询消息。LinkedIn、TikTok、YouTube 私信不纳入第一阶段固定交付范围，如后续需要自动化接入，需根据平台审核、账号条件和第三方服务商报价另行评估。

## 6. 可对客户这样说

> 老板可以这样理解：客户主动来问，我们接收消息基本不花钱；官网、Facebook、Instagram 正常回复也没有按条消息费；WhatsApp 在客户主动咨询后的 24 小时内回复也是免费的。真正会产生按条费用的是 WhatsApp 主动营销，比如主动给海外客户发产品推广、老客户唤醒消息，这个大概每条 0.17-0.50 元人民币，取决于客户所在国家。其他平台主要不是消息费，而是账号审核、会员工具或第三方服务费，所以第一阶段我们建议先做最稳的官网 + WhatsApp + Facebook / Instagram，把询盘接住、筛选出来、同步到飞书。
