## 🏢 客户公司与团队背景

### 国内团队架构（共 4 人）
- 统筹 1 人
- 技术设计 1 人
- 出口单证跟单 1 人
- 铝单板业务员 1 人
- **计划新增**：采购 1 人（负责供应链整合与生产跟进，实现专人专岗）
- **管理风格**：自由管理，团队多为宝妈，沟通以群内 / 当面即时解决为主，不喜欢开会

### 海外团队规划
- 未来计划在目标国家每个点位布局 1-2 人，拓展本地化团队

### 核心产品
- **主营品类**：门窗幕墙全品类外墙装饰产品
- **核心爆品**：铝单板（可用于外立面、室内、天花等多种场景）
- **中东优势**：铝单板在中东需求旺盛，双曲铝单板当地无法生产，只能从中国采购
- **第二业务线**：全铝国外全屋整装（门窗、淋浴房、护栏、天窗、定制柜、地砖、浴室柜等全品类）

### 业务模式
- 整体为 ToB 定制业务，单个项目货值从几十万到上千万不等
- 业务员一年做成 2 个订单即可覆盖成本，不需要大量开发客户
- 老客户复购稳定，新客户开发跑通链路后再扩招业务员，稳步扩张

## 🎯 四大核心需求

### 需求1：ToB 获客官网（铝单板单品独立站）+ AI 智能客服

#### 1.1 旧官网问题
- 运营 5-6 年，由 SEO 服务商打包开发
- **域名、源代码都不属于甲方**，无法独立修改运营
- 产品大而全，不符合当前爆品聚焦策略
- 引来的多为 ToC 小客户，不符合 ToB 大客户定位

#### 1.2 新官网定位
- **铝单板单品独立站**（聚焦爆品，原有其他产品后续拆分到另外的官网分别推广）
- 面向 ToB 大客户（非 ToC 小客户）
- 针对中东迪拜、沙特、卡塔尔、美国、澳洲等优质市场
- **仅做展示，不做电商下单**
- **多语言**：支持英文、阿拉伯语两种语言，**不开放中文访问**
- **新旧站分工**：新站专推铝单板；旧站保留或承接门窗 / 全屋整装等其他业务线，并逐步移除铝单板相关内容，避免定位冲突
- **持续运营定位**：先搭建官网框架，后续持续补充产品、案例、安装视频、News / Blog 内容

#### 1.3 官网功能模块
- ✅ 首页
- ✅ 产品介绍
- ✅ 项目案例
- ✅ 关于我们
- ✅ 联系我们
- ✅ News / Blog（一期必做，用于 SEO / GEO 内容更新）
- ✅ 预留图册、技术参数下载入口
- ✅ 谷歌 SEO + GEO 关键词体系梳理
- ✅ 链接所有社媒渠道（Facebook、LinkedIn、Instagram、WhatsApp、YouTube、TikTok）
- ✅ 后台 / CMS：产品、案例、技术参数、图册、文章可由甲方持续维护
- ✅ 直接联系入口：客户可能不愿填写表单，应优先提供 WhatsApp / 社媒私信 / AI 客服等即时入口

#### 1.4 图片展示规划
- 项目案例放效果图
- **增加工厂生产实拍图**，保证真实性
- 客户不返回实装效果图的，可用 AI 生成效果图补充
- 可通过 AI 单独放大标注产品位置，突出产品细节，符合 ToB 客户浏览习惯
- 产品图和案例图需同时兼顾“真实生产能力”和“外贸展示质感”，避免只有效果图导致客户误判为纯贸易 / 电商公司

#### 1.5 官网所有权（重要）
- 使用甲方自己的域名
- 源代码放在甲方自己的服务器
- 完全归甲方所有，不依赖第三方服务商
- 后台数据、产品素材、客户线索归甲方所有

#### 1.6 AI 智能客服需求
- **核心功能**：自动回复简单问题 + 前期客户意向筛选
- **目标**：仅将高意向精准客户推送给业务人员
- **支持渠道**：网站、WhatsApp、Facebook、LinkedIn、Instagram 等多渠道
- **多语言支持**：英文、阿拉伯语等
- **关键更正**：06-17 会议确认后，AI 客服不应只按“官网插件”理解，而应作为跨社媒统一消息入口的一部分
- **知识库输入**：产品手册、技术参数、销售话术、常见问答、历史客户聊天记录、意向判断规则
- **筛选目标**：尽量在 2-3 轮对话内判断客户意向，低意向客户由 AI 先行过滤，高意向客户尽快转人工

### 需求2：AI 赋能社媒自动化运营（整合多平台）

#### 2.1 现有获客渠道现状
| 渠道 | 现状 | 问题 |
|------|------|------|
| 主动发帖联系客户 | 唯一在运行渠道 | 客户质量不佳 |
| 现有官网谷歌自然流量 | 选对关键词可排第三位 | 流量尚可 |
| YouTube | 仅作展示平台 | 不具备获客能力 |
| Facebook 广告 | 未启用 | 计划策划完善后再启动 |
| Facebook 获客 | 垃圾客户较多 | 客户质量不佳 |
| WhatsApp | 客户多 | 疏于跟进 |
| 主动群发 | 100 个客户回复 5-6 个 | 转化率低 |
| 国内抖音 | 运营 2 个账号（铝单板 + 全屋定制） | 国内市场 |

#### 2.2 成品工具痛点（对标产品）
- **对标产品：易飞伦**
  - 年费 49800 元，可开 5 个多语言账号
  - 支持 AI 生成内容、一键分发多平台、统一回复客户消息、AI 自动回复客户咨询
  - 功能符合需求，但**价格过高**
- 其他同类一体化工具费用普遍数万元
- 成品工具功能分散，需人工复制粘贴，操作效率低

#### 2.3 核心功能需求
- **多平台打通**：Facebook、WhatsApp、LinkedIn、Instagram 等海外社媒
- **多平台消息统一接收**：所有平台客户消息汇集到一个入口
- **AI 自动回复**：初步筛选客户，高意向客户再转人工跟进
- **AI 内容生产**：多语言图文、视频内容生成
- **一键分发**：人工审核后分发到对应平台账号
- **多账号管理**：支持多个多语言账号
- **统一回复工作台**：不同平台、不同语言账号的客户消息统一查看、统一回复、统一转人工
- **新旧账号策略**：需评估继续使用旧账号、申请新账号、养号周期和账号归属

#### 2.4 AI 内容生产需求
- **AI 图片生成**：批量生产社媒配图
- **AI 视频剪辑**：自动化视频内容生产
- **AI 文案撰写**：多平台、多语言文案自动生成
- **爆款内容改写**：参考高表现内容生成适合铝单板 / 全屋整装业务的版本
- **人力投入**：基础操作交由低成本兼职人员完成，仅需人工审核内容对错，生成失败重试即可

#### 2.5 技术落地优势
- 🇨🇳 国内平台：对 AI 自动发文、批量操作监管严格，容易封号
- 🌍 海外平台：相对可优先验证脚本化发布，可通过打开网页自动操作方式降低官方接口依赖
- ⚠️ 风险边界：仍需验证账号授权、账号风控、IP 地区、平台条款、验证码 / 二次验证、脚本稳定性，不应直接承诺“长期无限制自动发布”

#### 2.6 AI 模型分工（整合多模型优势）
| 任务 | 推荐模型 | 优势 |
|------|----------|------|
| 生图 | GPT | 效果最好 |
| 视频剪辑 | 豆包 | 体验更好 |
| 梳理思路 / 做策划 | Gemini | 更客观理性 |
| 写代码 | Claude | 更擅长 |

#### 2.7 成本目标
- 参考旅修行业案例：单张图成本 0.4-0.5 元，一天产出 1000+ 张图
- **本方案整体报价约一两万**（整合多模型核心能力，去掉冗余功能，远低于市面同类工具）

### 需求3：全链路客户管理联动（飞书 CRM + 自动化跟进）

#### 3.1 现有痛点
- 自然到访客户较多，人工管理容易遗忘，导致跟进不及时
- 已申请飞书，尝试用飞书多维表格做简易 CRM，因不会使用 + 供应商习惯用微信，项目暂时搁置
- 内部沟通目前微信更多，飞书提醒要真正落地，需要确认哪些人员必须进入飞书流程

#### 3.2 客户分级自动提醒（核心需求）
| 客户等级 | 跟进频率 |
|----------|----------|
| A 类客户 | 每周跟进 1 次 |
| B 类客户 | 每两周跟进 1 次 |
| C 类客户 | 每 15 天跟进 1 次 |

- 还需生日等场景自动提醒
- 业务员把客户录入系统后，系统按设定的频率自动提示是否该跟进

#### 3.3 具体需求
- **客户信息自动录入**：AI 客服筛选的客户信息自动同步到飞书
- **人工客户录入**：业务员 / 跟单人员可手动录入线下、WhatsApp、展会、老客户转介绍等来源客户
- **跟进记录管理**：所有跟进记录可录入系统
- **自动提醒功能**：新增客户自动 @ 对应跟单人员；按分级频率自动提醒跟进
- **客户画像生成**：AI 自动整理生成客户画像
- **老客户盘活**：方便后续精准推送
- **渠道归因**：记录客户来自官网、LinkedIn、Facebook、WhatsApp、SEO 关键词、投流活动或人工开发，便于后续判断渠道质量

#### 3.4 客户分配规则
- 目前团队规模小，**暂无客户归属与提成分配需求**
- 未来团队扩张后，可能增加分层提成机制

#### 3.5 系统选型建议
- 采用飞书多维表格（轻量级 CRM）
- 不需要一开始就上重型 CRM 或 ERP
- 适合中小企业，成本低且成熟
- MVP 阶段以客户档案、跟进记录、自动提醒、客户画像为核心，不做复杂客户归属 / 提成结算
- 待确认：飞书消息是否足够，是否需要同步到微信 / 企业微信群作为提醒兜底

### 需求4：未来可复制推广（商业拓展）

- 项目跑通后，复制推广给佛山本地其他中小生产外贸企业

## 🔄 全链路业务流程设计

### 阶段1：多渠道获客
```
谷歌SEO搜索 ──┐
GEO/AI搜索曝光 ─┤
Facebook 投流 ─┤
LinkedIn 主动开发 ─┤
Instagram ────┤  ──→  铝单板单品独立站
YouTube ──────┤     （英文 / 阿拉伯语）
TikTok ───────┤
WhatsApp ─────┘
```

### 阶段2：AI 客服筛选
```
客户进入官网 / 社媒咨询
    ↓
AI 客服自动回复简单问题 + 初步沟通
    ↓
意向判断（高 / 中 / 低）
    ↓
高意向客户留联系方式
    ↓
统一回复工作台转人工跟进
```

### 阶段3：客户信息自动入库
```
AI 筛选出的高意向客户 ──┐
业务员 / 跟单手动录入客户 ─┤
老客户 / 转介绍补充客户 ───┘
    ↓
自动同步到飞书多维表格
    ↓
自动 @ 对应跟单人员
    ↓
发送跟进提醒
```

### 阶段4：分级跟进管理
```
跟单人员接收提醒
    ↓
查看客户信息 + AI 生成的客户画像
    ↓
按 A/B/C 分级频率跟进
   - A 类：每周 1 次
   - B 类：每两周 1 次
   - C 类：每 15 天 1 次
    ↓
每次跟进记录录入系统
    ↓
生日等场景自动提醒
```

### 阶段5：AI 辅助分析与内容闭环
```
系统累积跟进记录
    ↓
AI 自动更新客户画像
    ↓
识别客户需求偏好
    ↓
推荐精准产品 / 方案 → 盘活老客户
    ↓
AI 生成多语言图文 / 视频 → 人工审核 → 一键分发社媒
    ↓
社媒数据反馈 → 优化内容生产
```

## 💡 战略建议（来自志云）

### 1. 先跑通单流程，再放大流量
- ❌ 不建议：ROI 未跑正前盲目上批量工具投流
- ✅ 建议：先跑通单平台流程，验证获客转化逻辑
- 📊 目标：确认能获得正营收后再批量上账号、放大流量

### 2. 海外平台规则优势
- 🇨🇳 国内平台：对 AI 自动发文、批量操作监管严格，容易封号
- 🌍 海外平台：Facebook、LinkedIn、TikTok 等目前相对更适合做脚本化验证
- ✅ 结论：优先验证“人工审核 + 脚本化辅助发布”，并将账号风控、IP 地区、验证码、平台条款作为实施前置风险

### 3. 轻量级客户管理方案
- 飞书多维表格足够满足中小企业需求
- 初期不需要上重型 CRM 或 ERP 系统
- 可满足：自动录入、分级跟进提醒、客户画像生成
- 但需确认内部成员对飞书提醒的使用习惯，必要时增加微信 / 企业微信群通知兜底

### 4. 爆品聚焦策略
- 新官网聚焦铝单板单品，原有其他产品后续拆分到独立官网分别推广
- 避免"大而全"稀释 ToB 大客户定位
- 新站上线后，旧站中铝单板相关内容需逐步移除或弱化，旧站继续承接门窗 / 全屋整装等其他产品线

## 🛠️ 技术架构分层

### Layer 1：前端获客渠道层
- 谷歌 SEO
- 社媒平台（Facebook、LinkedIn、Instagram、WhatsApp、YouTube、TikTok）

### Layer 2：官网展示层（铝单板单品独立站）
- 首页 / 产品介绍 / 项目案例 / 关于我们 / 联系我们
- News / Blog（一期必做，用于持续 SEO / GEO 内容更新）
- 效果图 + 工厂实拍图（AI 补充生成、放大标注）
- 图册 / 技术参数下载入口
- 英文 + 阿拉伯语（不开放中文）
- 甲方自有域名 + 自有服务器
- 谷歌 SEO + GEO 关键词体系
- 后台 / CMS：产品、案例、图册、技术参数、文章可持续维护
- 即时联系入口：WhatsApp / 社媒私信 / AI 客服优先，表单作为辅助

### Layer 3：AI 智能客服层
- 客服机器人（自动回复简单问题）
- 意向筛选引擎
- 多语言支持（英文 / 阿拉伯语）
- 多渠道接入（网站 / WhatsApp / Facebook / LinkedIn / Instagram）
- 客户信息采集
- 业务知识库 / 话术库：产品手册、技术参数、销售话术、历史聊天记录、FAQ

### Layer 4：AI 内容生产层
- AI 图片生成（GPT）
- AI 视频剪辑（豆包）
- AI 文案生成（多语言）
- 多平台内容适配
- 素材库管理

### Layer 5：社媒自动化运营层
- 社媒发布引擎（脚本化发布，优先减少官方接口依赖）
- 多账号管理（多语言账号）
- 定时发布 / 一键分发
- 多平台消息统一接收
- 数据分析反馈
- 账号与运行环境验证：新旧账号策略、养号、授权方式、IP 地区、验证码 / 二次验证、平台风控

### Layer 6：客户管理层（飞书 CRM）
- 客户信息库
- 客户画像生成
- 跟进记录管理
- 自动提醒系统（A/B/C 分级 + 生日提醒）
- 客户分级
- 人工录入入口
- 渠道来源 / 互动记录 / 跟进状态归因
- 飞书提醒与微信 / 企业微信兜底通知待确认

### Layer 7：业务人员层
- 跟单人员
- 销售团队
- 运营人员 / 兼职人员（提供素材 + 审核内容）

### Layer 8：AI 核心引擎（多模型整合）
- 大语言模型：Claude（写代码）/ Gemini（策划）/ 豆包（视频）
- 图像生成模型：GPT
- 视频生成模型：豆包
- 数据分析引擎

## 🧱 非功能与交付约束（补充）

### 安全与权限
- 客户联系方式、聊天记录、跟进记录属于敏感业务数据，应控制后台、飞书表格、社媒账号的访问权限
- 大模型 API Key、社媒账号、平台授权信息需加密保存，不应明文散落在代码或共享文档中
- 多账号发布涉及平台规则与授权边界，交付前需明确由甲方账号授权并确认可接受的操作方式

### 稳定性与可恢复
- 官网、AI 客服、社媒消息接入、飞书同步需保留失败重试与错误日志
- 客户线索入库失败时应有人工可查的失败队列，避免高意向客户丢失
- 飞书 CRM 数据应定期备份或至少支持导出

### AI 效果验收
- AI 客服需围绕固定产品知识、销售话术、客户意向判断规则做测试集
- 同类问题回复应保持稳定，不能频繁“飘”；高意向识别应优先降低漏判
- 内容生成必须保留人工审核，不直接全自动发布

### 成本与扩展
- MVP 阶段优先跑通单品、单市场、单核心平台闭环，避免一次性铺开多账号多市场
- 模型调用、图片 / 视频生成、服务器、代理 / 网络环境、飞书或第三方平台费用需单独核算
- 后续复制到其他佛山企业时，应把行业知识库、产品素材、话术模板做成可替换配置，而不是硬编码

## 📌 关键成功因素

1. ✅ **战略先行**：先跑通单流程，再放大流量
2. ✅ **轻量起步**：用飞书等成熟轻量工具，避免过度工程
3. ✅ **爆品聚焦**：新官网聚焦铝单板单品，避免大而全
4. ✅ **AI 赋能**：重复性工作交给 AI，人负责高价值决策
5. ✅ **数据闭环**：全链路打通，客户信息自动沉淀
6. ✅ **自主可控**：官网域名 + 源代码 + 服务器完全归甲方所有
7. ✅ **多模型整合**：各任务用最擅长的模型，整合实现最优效果
8. ✅ **知识库质量**：产品手册、技术参数、销售话术、历史对话决定 AI 客服效果上限
9. ✅ **风控可控**：社媒自动化必须先验证账号、IP、平台规则与脚本稳定性
