# 验收报告

## 已满足

- 客户可在一份包含 7 个工作表的工作簿中提供无敏感信息的企业、资产、授权状态和交接资料。
- 客户账号注册、企业资产与最终管理员归属明确由客户负责；IVYBM 的协助范围被限制为书面授权后的集成配置、审核材料和受控联调。
- Meta Page task 与 Instagram“Allow access to messages”均有对应的非密证据字段。
- Meta、TikTok、LinkedIn 的条件/阻塞口径与一期冻结范围一致。
- LinkedIn API 受限时明确使用人工发布辅助，不宣传自动发布已经可用。

## 未满足（外部条件）

- Meta / TikTok / LinkedIn 真实 OAuth、Webhook 和受控发布。
- TikTok 私信官方 schema 与目标地区资格。
- Markdown → HTML 的本机重建（当前机器没有 `pandoc`）。

这些项按一期 P1 条件交付保留为 `blocked`，不是代码完成声明。
