## 2. 接口与业务契约

- `ContentQuery` 增加可选 `sort?: 'created' | 'updated' | 'website'`，旧调用默认 `created`。
- `parseContentQuery(input: Record<string, string | string[] | undefined>): ContentQuery` 与 `getContentSummary({ payload, query, req }): Promise<ContentSummary>` 保留签名。
- `ContentSummaryItem` / `ContentCommandResult` 增加 `createdAt: string`、`publishedAt: string | null`；`updatedAt` 保留用于详情和乐观锁。
- `/dashboard/content?sort=created|updated|website`：默认创建倒序；更新时间模式按更新倒序；官网模式仅用于产品、案例、新闻、知识，并固定已发布状态，按首次发布时间倒序。所有模式按 ID 兜底。
- 左侧列表按模式显示“创建于 / 更新于 / 发布于”；详情“最后更新”不变。分类卡片继续统计最后更新，增加明确标签。
- 按用户后续确认，新增入口只保留页面右上角；详情卡片只显示当前内容的编辑和预览操作。`ContentEditorActions({ onCreate?, onEdit? })` 按实际传入的操作显示按钮。
- `firstPublishedAtField: Field`，`preserveFirstPublishedAt: CollectionBeforeChangeHook`：草稿无发布日期；首次发布由服务端记录；编辑、翻译、下架、重新发布、客户端传入日期均不能改变已有日期。受信 seed 的 `context.importPublicationDate === true` 仅允许初始化历史日期。
- 历史回填保留文章已有 `publishedAt`，缺失时使用最早可用已发布版本的文档更新时间，最终回退文档创建时间；从未发布的草稿保持 NULL。直接 SQL 回填不修改任何 `created_at`、`updated_at` 或正文；版本时间也保持不变。回退移除新增字段/索引，文章原有字段及已补齐日期保留。
- 英/阿共用非本地化的首次发布时间和固定次序；首页继承列表顺序。
