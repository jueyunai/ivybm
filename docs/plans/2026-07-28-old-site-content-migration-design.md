# 旧站内容迁移到本地官网设计

## 目标

在不扩大产品目录的前提下，把客户确认可用的旧站资料迁入最新官网本地环境，形成可完整浏览的英文 / 阿语演示版本。产品仍只保留标准铝单板、单曲铝单板和双曲铝单板三类。

## 首版范围

- 用旧站真实项目替换六个通用占位案例：Canada Double-Curved、Hong Kong Tuen Mun Double-Curved Copper Panel、Shunde Gymnasium。
- 每个项目写入封面、图库、项目简介和应用信息；不新增视频字段，首版只使用图片。
- 用旧站工厂、设备、质检和装运图片替换 About 页的通用图库，并写入铝单板相关的 IQC、IPQC、FQC、OQC、QA / CA 流程内容。
- 用旧站资料填充三篇技术文章：双曲铝单板、表面处理、铝单板厚度选择。
- 写入已确认的工厂地址、电话和邮箱，并统一 Contact 表单中的产品名称。
- 正式图片保存在仓库外受控资料目录，本地可通过显式的外部目录配置导入；production 通过 Payload Media 受控上传。Git 和 Docker 镜像只保留初始化占位图，页面不热链旧站。

## 数据与页面

迁移内容继续使用现有 `Pages`、`Projects`、`Posts`、`Media` 和 `SiteSettings`，不新增 Collection、migration 或共享契约。Rich Text 由本地纯函数生成 Lexical 数据，项目详情页读取现有 `gallery` 字段展示多图。

Seed 应可重复运行：默认用 Git 中的占位图按稳定 slug 更新本地演示内容，删除本次明确替换的占位项目和占位文章，保留其他人工创建的数据。只有本地显式配置仓库外素材目录时才读取正式图片；production 禁止通过 seed 加载客户素材，媒体由 CMS 上传并记录来源与授权状态。

## 产品详情采购体验补充

产品详情按海外幕墙采购经理的决策顺序组织，不新增 Collection 或 migration：首屏保留图库和规格摘要，正文使用现有 `Products.description` 写入产品定义、适用场景、工程协同、质检与交付、询价输入和常见问题；页面侧增加明确的项目询价入口与相关项目 / 技术文章证据。

所有旧站数值和能力描述只作为历史资料线索。厚度、合金与状态、最大尺寸、曲率、涂层、性能、认证、质保、MOQ、交期、包装和贸易条款必须以批准图纸、样板、当前证书、工程评审及合同确认为准；本地演示不把这些内容写成无条件保证。

产品图库增加可访问的全屏灯箱：主图点击或“查看大图”按钮打开，支持前后切换、缩略图、Esc 关闭、方向键（含 RTL 方向）、遮罩关闭、焦点恢复和页面滚动锁定。灯箱和缩略图使用 `object-fit: contain`，优先展示完整构图，不裁切成封面缩略图。

移动端产品页提供页内询价 CTA，并用稳定产品 slug 预填 Contact 的产品兴趣；固定聊天入口不能遮挡图库缩略图或主要操作。

## 产品与新闻图文化补充

图库主图、缩略图和灯箱统一使用原始媒体，而不是 `thumbnail` / `large` 的裁切派生图；主图和灯箱使用 Next Image `fill` 配合 `object-fit: contain`，由预览容器的宽高限制最长边，使宽图、方图和竖图都能在单个窗口内完整展示，同时允许较小原图在不改变比例的前提下放大到可读尺寸。

产品正文在已有采购说明之后复用各 SKU 现有 4 张旧站详情图，按项目 / 制造证据图组展示；参数表复现旧站 Curved Aluminum Panels 页面中的产品家族、形态、历史尺寸范围、几何、表面、颜色和应用字段。表头和提示必须明确这些是旧站归档数据，不是当前报价、尺寸公差或合规声明。

厚度文章复用旧站正文实拍图，并恢复 1.5→1.35、2.0→1.85、2.5→2.35、3.0→2.85、4.0→3.9、5.0→5.0 mm 六行历史对照表；发布日期恢复为旧页的 2026-04-13。来源页面没有给出检测方法或标准条款，因此正文必须提示按项目标准、材料、荷载、表面和验收方法重新确认。

## 验收

- 英文和阿语首页、About、Projects、Project Detail、News、News Detail、Contact 均可加载。
- 三个项目详情有正文和多图；三篇新闻详情有完整正文。
- 产品正文包含旧站实拍图和带来源边界的历史参数表；厚度新闻包含正文实拍图和六行对照表。
- Footer 和 Contact 显示真实联系方式，产品选项命名一致。
- 三个产品都有英文 / 阿语正文、项目参数免责声明、询价输入和 FAQ；详情页可进入带产品上下文的询价表单。
- 主图和缩略图展示完整构图；灯箱在桌面、移动端和 RTL 下可用键盘与触控操作。
- lint、typecheck、unit / integration、build 通过；桌面和移动端截图无破图、溢出或明显布局问题。
- 本地确认前不 push、不创建 PR、不执行生产 seed 或部署。

## 发布与素材边界

- 正式产品、项目、工厂、新闻图片及 PDF 不进入 Git，也不进入 CI 构建上下文或 runtime / worker 镜像。
- 本地私有素材目录不属于任何 worktree；`.gitignore` 与 `.dockerignore` 同时拒绝历史正式素材路径，防止误提交或误打包。
- Task 6 代码合并 `main`、CI 成功并部署不可变 SHA + digest 镜像后，先验证旧内容，再备份 production PostgreSQL 与媒体卷，通过 Payload CMS 上传正式媒体并更新内容引用。
- 镜像回滚不能恢复 CMS 内容；正式媒体和内容写入前必须保存数据库、媒体卷和 SHA-256 清单。
