## 3. 接口与交互契约

### 3.1 首页优先事项深链

```typescript
export const priorityHref = (
  kind: PortalOverviewPriorityItem['kind'],
  id: number | string,
): string => {
  const encodedId = encodeURIComponent(String(id))

  switch (kind) {
    case 'active-conversation':
    case 'handoff-request':
      return '/dashboard/conversations?conversation=' + encodedId
    case 'lead':
      return '/dashboard/leads?lead=' + encodedId
    case 'job':
      return '/dashboard/operations?job=' + encodedId + '#portal-job-' + encodedId
  }
}
```

验收要求：链接不只跳转到模块，目标会话/线索/任务必须被加载、选中或明确高亮。

### 3.2 后台任务定位查询

```typescript
export interface SafeJobQuery {
  job?: number
  page: number
  status: SafeJobStatusFilter
}
```

- `parseSafeJobQuery` 只接受正整数 `job`，无效值按未指定处理；
- 指定 `job` 时使用 Payload 查询权限读取该任务，不用前端 mock 或绕过 access control；
- 目标不存在或不可见时显示普通空状态，不泄露任务是否真实存在。

### 3.3 知识库工作区

```typescript
export type KnowledgeWorkspaceTab = 'documents' | 'debug'
export type KnowledgeWorkspaceDrawer = 'ingest' | null
```

- 默认打开 `documents`；`?tab=debug` 打开 AI 调试；`?drawer=ingest` 打开入库抽屉；
- Tab 必须具有 `tablist/tab/tabpanel`、`aria-selected`、roving `tabIndex` 以及 ArrowLeft/ArrowRight/Home/End 键盘契约；
- 文档列表整行可点击和键盘激活，打开新建/入库态时清除旧文档选中态；
- 入库抽屉关闭后返回触发按钮，移动端不得水平溢出。

### 3.4 弹窗与统一选择器

```tsx
<Dialog.Content className="portal-shell portal-surface portal-modal">
  {/* header, close button, form, actions */}
</Dialog.Content>
```

- `UiSelect` 内的原生 `<select>` 始终可见、可聚焦、可被 `<label>`/`aria-label` 命名并且可被 Playwright `selectOption()` 操作；
- 不允许同一字段渲染两套可交互选择器；
- 必填字段传递 `required`，名称、值和表单提交语义与当前后端契约一致。
