# Task 11 飞书 CRM 一键连接产品设计

## 决策

默认体验是“连接飞书”，不是“创建飞书应用”。客户管理员点击一次链接、完成授权后，IVYBM
自动创建 CRM 多维表格并开始同步。免费飞书租户可用，不以企业版为前提。

企业版 / 旗舰版专属的行列级高级权限不进入一期依赖。跟进提醒使用普通日期字段；
`Leads.nextFollowUpAt` 是服务端权威到期时间，durable worker Job 负责通知，Base 视图 / Workflow
只作为客户侧辅助，不是可靠性前提。高级权限不可用不应导致连接失败。

## 用户流程

1. Payload Admin 显示未连接、已连接、需重新授权或错误状态。
2. 管理员点击“连接飞书”，跳转飞书官方授权页。
3. 授权成功后自动创建 `IVYBM 客户管理` Base 与“客户档案”表。
4. 系统保存 Base 链接、启用主映射，并把安装管理员设为默认通知接收人。
5. 管理员可打开 Base、补充销售成员映射；token 过期由系统自动刷新。
6. 主动断开需管理员确认；系统原子清除本地 token 并停用相关映射，失败则保持原连接状态；重新连接重新走官方授权。

## 状态与边界

- `connected`：凭据可解密、Base 已创建、映射已激活。
- `reconnect_required`：refresh token 失效、撤销或超过飞书重授权周期。
- `disconnected`：本地凭据已清除、同步停用。
- `error`：授权后建表失败或环境配置错误，必须展示稳定错误码，不展示 token。
- 应用商店审核 / ISV 资质是生产外部前置条件；未满足时只交付代码契约和阻塞证据。
- 手动企业自建应用仍可作为运维兜底，但 UI 不引导普通客户使用。
