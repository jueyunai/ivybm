# Task 11 飞书 CRM 一键连接产品设计

## 决策

默认体验是“扫码连接飞书”，不是让客户进入开放平台手工创建应用。客户管理员扫码确认后，
IVYBM 通过飞书官方能力为该租户创建专属自建应用，再完成用户 OAuth，自动创建 CRM 多维表格并开始同步。
免费飞书租户可用，不以企业版、ISV 商店上架或客户复制 App ID / Secret 为前提。

企业版 / 旗舰版专属的行列级高级权限不进入一期依赖。跟进提醒使用普通日期字段；
`Leads.nextFollowUpAt` 是服务端权威到期时间，durable worker Job 负责通知，Base 视图 / Workflow
只作为客户侧辅助，不是可靠性前提。高级权限不可用不应导致连接失败。

## 用户流程

1. Portal `/dashboard/leads` 显示未连接、扫码中、授权中、已连接、需重新授权或错误状态。
2. 管理员点击“扫码连接飞书”，使用飞书扫码并确认创建租户专属应用。
3. 系统自动配置回调地址，随后跳转飞书完成用户 OAuth。
4. 授权成功后自动创建 `IVYBM 客户管理` Base 与“客户档案”表。
5. 系统保存 Base 链接、启用主映射，并把安装管理员设为默认通知接收人。
6. 管理员可打开 Base、补充销售成员映射；token 过期由系统使用该租户应用凭据自动刷新。
7. 主动断开需管理员确认；系统原子清除本地 token 和租户 App Secret 并停用相关映射，失败则保持原连接状态。

## 状态与边界

- `connected`：凭据可解密、Base 已创建、映射已激活。
- `reconnect_required`：refresh token 失效、撤销或超过飞书重授权周期。
- `disconnected`：本地凭据已清除、同步停用。
- `error`：授权后建表失败或环境配置错误，必须展示稳定错误码，不展示 token。
- `FEISHU_QR_REGISTRATION_ENABLED` 默认关闭；生产只在回调、加密密钥和受控扫码验收后人工开启。
- 统一商店应用 OAuth 与手动自建应用继续作为兼容 / 运维兜底，Portal 不引导普通客户使用。
